# Hybrid LLM + RL Trading: Evidence, Ablations, and Gaps

## Executive Summary

- **Strongest same-policy evidence**: SAPPO reports LLaMA sentiment-augmented PPO versus the same PPO with lambda = 0, while FinRL-DeepSeek reports PPO/CPPO variants across LLM-infusion levels. These are the clearest tests of whether an LLM adds value to an RL policy. [6] [10]
- **Signal augmentation is the dominant pattern**: FinRL-DeepSeek, SAPPO, and HARLF use language-model outputs as sentiment, risk, or news-derived state information rather than as a standalone portfolio policy. [10] [6] [7]
- **The strongest positive result is conditional**: SAPPO improves its PPO baseline on a three-stock portfolio, but FinRL-DeepSeek shows LLM infusion degrading PPO while improving CPPO at the reported infusion levels. [6] [10]
- **Reward shaping is emerging, not mature**: GIFT makes the LLM propose state and reward interfaces while PPO still produces portfolio actions; its component deltas are positive relative to full GIFT, but exact Pure-PPO versus component-only numerical tables are not reported in the accessible evidence. [8] [8]
- **Hierarchical control is not the same as LLM planning**: HARLF has base, meta, and super agents, but its LLM is documented as a sentiment feature extractor, not an independently evaluated high-level planner. [7] [7]
- **Direct RL-tuning of an LLM has weak ablation evidence**: Trading-R1 uses supervised fine-tuning followed by reinforcement learning, and FLAG-Trader uses a partially fine-tuned LLM policy, but neither supplies a same-policy non-LLM RL comparison in the cited evidence. [25] [25] [21]
- **Alpha mining is mostly adjacent to hybrid portfolio RL**: AlphaAgent, Alpha-GPT, and QuantAgent generate or select factors/signals, but their reported systems are not demonstrated as the requested LLM-feature-plus-PPO/SAC/DQN portfolio policy with a same-policy LLM removal ablation. [9] [13] [12]
- **Negative evidence is material**: A multi-seed Nasdaq-100 repository reports 166.34% mean return for full signal coverage, versus 121.27% without signals, but its public evidence does not report exact calendar dates, transaction costs, or a named external baseline. [5] [5]

## Synthesis

| Dimension | Feature/signal augmentation | Reward/interface shaping | Planner/executor hierarchy | RL-tuned LLM | Alpha-factor generation |
|---|---|---|---|---|---|
| Where the LLM enters | State, advantage, risk, or recommendation channels. [10] [6] | Executable state and reward components while PPO remains the action learner. [8] | High-level strategy guidance or regime aggregation, but HARLF's LLM is documented mainly as a sentiment extractor. [22] [7] | The LLM itself is the policy or is post-trained with trading rewards. [25] [21] | Factor hypotheses, formulas, or code are generated for downstream quantitative evaluation. [9] [13] |
| Best verified comparison | SAPPO lambda = 0 PPO; FinRL-DeepSeek PPO/CPPO infusion sweeps. [6] [10] | GIFT component-removal deltas; exact absolute component table NOT REPORTED. [8] | RL-only comparison in guided RL; no explicit same-policy deletion proof. [22] | Trading-R1 warm-start/RL-only initialization comparison, not no-LLM policy. [25] | No same-policy no-LLM ablation in AlphaAgent, Alpha-GPT, or QuantAgent. [9] [13] [12] |
| Main trade-off | Easy to plug into PPO/CPPO, but value is policy- and coverage-dependent. [10] | Can encode risk constraints and diagnostics, but attribution between state and reward components remains incomplete. [8] | Can separate long-horizon intent from local execution, but cost and date omissions make results hard to reproduce. [22] | Allows direct optimization of reasoning and recommendations, but lacks a clean non-LLM counterfactual in the cited papers. [25] [21] | Expands research search, but factor predictive metrics are not portfolio-RL performance. [12] [9] |
| Evidence quality | Highest among the five patterns because two studies expose same-family no-LLM comparisons. [6] [10] | Promising but incomplete because the exact absolute PPO/component ablation table is not available in the cited evidence. [8] | Moderate for architecture, weak for causal attribution. [22] [7] | Architecture is demonstrated, incremental value is not. [25] [21] | Mostly adjacent evidence, not direct hybrid portfolio-RL evidence. [13] [9] |

**Bottom line:** For a deployable research program, start with a fixed PPO or CPPO policy, add one LLM channel at a time, and publish the exact universe, calendar split, costs, seeds, and same-policy no-LLM result. The current literature supports that protocol as a measurement requirement, not a conclusion that LLM augmentation is reliably profitable.
