# Named LLM Trading and Financial Decision-Agent Systems, 2023-Sep 2026

## Evidence and reporting rules

| Rule | Applied treatment |
|---|---|
| Coverage | Named systems, alpha-mining systems, trading frameworks, financial agents, and evaluation benchmarks with a live paper or repository URL. The 2024 survey covered 27 LLM trading papers; the 2026 protocol audit identified 77 studies, but only 19 met its closed-loop empirical threshold. [7] [9] |
| Performance gate | Every reported performance number is accompanied in the same row by asset universe, exact test window, transaction costs, and baseline. Missing fields are written exactly as **NOT REPORTED**. |
| Comparability warning | The 2026 audit found only 2/19 primary studies with an extractable time-consistent split, 1/19 with a transaction-cost model, 1/19 with universe/survivorship handling, and 0/19 at its highest reproducibility level. [9] [9] |
| Metric scope | CR means cumulative return when the source uses that term; AR/IR/Sortino/Information Ratio are not relabeled as CR or Sharpe. Benchmarks and financial LLMs without a closed-loop trading result retain **NOT REPORTED** for CR, Sharpe, and MDD. |

## Independent replications, reproducibility tests and criticisms

| Item | Finding | Source URL |
|---|---|---|
| FinMem | TanTaf published an independent from-scratch implementation of the FinMem architecture and explicitly notes that the paper does not publish at least one exact constant, such as the access-counter promotion threshold. [61] | https://github.com/TanTaf/Finmem |
| TradingAgents | A published reproducibility study evaluates the framework with GPT-4o and Qwen3:30B while varying temperature, seed and sampling parameters. The accessible source confirms the replication design; a definitive success/failure claim is NOT REPORTED in the retrieved excerpt. [62] | https://dl.acm.org/doi/10.1145/3800973.3801029 |
| HedgeAgents | JansenAnalytics labels its repository a faithful replication/template of the HedgeAgents paper, but the retrieved source does not provide an independent performance result. [43] | https://github.com/JansenAnalytics/hedge-agents |
| TradingAgents deployment caveat | The project warns that performance can vary with backbone model, temperature, trading period, data quality and nondeterministic behavior. [58] | https://tauricresearch.github.io/TradingAgents/ |
| StockAgent external-validity caveat | The ACM description characterizes StockAgent as a simulation for examining behavior and profitability and says it has no empirical validation for real-world use. [34] | https://dlnext.acm.org/doi/10.1145/3844605 |
| Literature-wide reproducibility | The 2026 audit found sparse protocol-critical reporting, only 4/19 primary studies exposing artifacts beyond narrative description, and 0/19 at its R3 reproducibility level. [9] [9] [9] | https://arxiv.org/html/2605.19337v1 |
| Literature-wide negative evidence | The audit says few papers report failed prompts, abandoned reward schemes, degraded live performance, or higher turnover without better net returns; it warns that missing negative results are a reporting limitation and that survivorship bias may affect both the survey and backtests. [9] | https://arxiv.org/html/2605.19337v1 |
| Main criticism of headline comparisons | The audit concludes that the literature is not yet protocol-comparable because time splits, costs, universe/survivorship handling and execution semantics are inconsistently reported. [9] | https://arxiv.org/html/2605.19337v1 |
